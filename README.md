# MK SYSTEM - إدارة البضاعة والمخزن

نظام حديث مبسط لإدارة بضاعة المخازن، عمليات الجرد، وتسجيل حركات البيع والسحب مع متابعة حية للتكاليف والأرباح المتوقعة والفعلية.

## المميزات الأساسية

- **لوحة مؤشرات مالية ذكية (KPIs)**:
  - إجمالي الكراتين وقطع الفرط المتاحة
  - إجمالي رأس مال البضاعة (التكلفة)
  - القيمة البيعية المتوقعة وصافي الأرباح المتوقعة
  - الأرباح الفعلية المحققة وإجمالي الدخل من المبيعات

- **إدخال بضاعة جديدة (دخول بضاعة)**:
  - احتساب تلقائي ثنائي الاتجاه لأسعار الشراء والتكلفة (سعر القطعة وسعر الكرتونة)
  - احتساب تلقائي ثنائي الاتجاه لأسعار البيع المستهدفة
  - دمج وتحديث تلقائي للأصناف الموجودة مسبقاً بالمخزن

- **عمليات البيع والسحب**:
  - إمكانية السحب بالكرتونة الكاملة أو بالقطع الفرط
  - فحص فوري لكفاية رصيد المخزن ومنع السحب الزائد
  - حساب فوري لمبلغ الفاتورة المطلوب من الزبون

- **جرد المخزن**:
  - بحث فوري وسريع عن البضاعة
  - بطاقات توضيحية لعدد الكراتين والقطع المتبقية مع تنبيه الأصناف المنتهية
  - إمكانية تعديل الأسعار والتفاصيل أو حذف الصنف

- **سجل حركات البيع**:
  - فلترة زمنية دقيقة: كل الأوقات، اليوم، آخر أسبوع، آخر شهر، أو نطاق تاريخ مخصص
  - بحث سريع باسم الصنف أو الملاحظات
  - حساب فوري لصافي المكسب وإجمالي الدخل للفترة المحددة

## التقنيات المستخدمة

- **React 19 + TypeScript**: بنية برمجية تفاعلية ومحكمة الأنواع
- **Vite**: بناء سريع وخفيف
- **Tailwind CSS**: تصميم نظيف، متجاوب، ومتوافق بالكامل مع اللغة العربية واتجاه RTL
- **Firebase Firestore / Offline Local Storage**: مزامنة سحابية مع دعم الحفظ المحلي في حال العمل دون اتصال

## طريقة النشر والتشغيل على GitHub Pages (حل الشاشة البيضاء)

تم تجهيز المشروع ليعمل بسلاسة تامة على GitHub Pages وتطبيقات WebView بدون شاشة بيضاء عبر الخيارات التالية:

### الطريقة الموصى بها (تفعيل GitHub Actions):
1. في مستودعك على GitHub، اذهب إلى **Settings** (الإعدادات).
2. من القائمة الجانبية اضغط على **Pages**.
3. في خانة **Source** تحت "Build and deployment"، اختر: **GitHub Actions**.
4. سيقوم GitHub تلقائياً ببناء وتشغيل الموقع فور أي تحديث.

### الطريقة البديلة (النشر من مجلد docs):
1. في **Settings -> Pages**.
2. تحت **Branch**، اختر `main` وحدد المجلد **`/docs`** ثم اضغط **Save**.
